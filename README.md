Network Information Tool

A beginner cybersecurity project written in Python that collects basic network information from the local computer.

What It Does

The program currently displays:

Computer name
Local IP address
Technologies Used

Python
Git
GitHub
VS Code
What I Learned

This project helped me practice:

Python fundamentals
Working with Python’s socket module
Understanding IP addresses and hostnames
Using Git for version control
Creating and managing a GitHub repository
How to Run

Make sure Python is installed, then run:

python network_info.py

The program will display the computer’s hostname and local IP address.
